===============================================================
  BEEANALIZ LOYIHASINI PYTHONANYWHERE GA YUKLASH VA ISHGA TUSHIRISH
===============================================================

1-QADAM: FAYLLARNI YUKLASH
---------------------------------------------------------------
1. pythonanywhere.com saytida ro'yxatdan o'ting yoki hisobingizga kiring.
2. Yuqori menyudan "Files" bo'limiga o'ting.
3. "Upload a file" tugmasi orqali "beeanaliz_server.zip" faylini yuklang.
4. "Open Bash console here" tugmasini bosing va quyidagi buyruqni yozib Enter bosing:
   
   unzip beeanaliz_server.zip -d mysite
   cd mysite

2-QADAM: KERAKLI KUTUBXONALARNI O'RNATISH
---------------------------------------------------------------
O'sha Bash konsolda quyidagi buyruqni kiriting:

   pip install -r requirements.txt

(Kutubxonalar: fastapi, uvicorn, pydantic, python-barcode, a2wsgi muvaffaqiyatli o'rnatiladi)

3-QADAM: WEB APP YARATISH VA SOZLASH
---------------------------------------------------------------
1. Yuqori menyudan "Web" bo'limiga o'ting.
2. "Add a new web app" tugmasini bosing.
3. Quyidagi bosqichlarni tanlang:
   - "Next"
   - "Manual configuration" (Flask yoki boshqasi emas, aynan Manual configuration)
   - Python versiyasini tanlang (masalan, Python 3.10)
   - "Next"

4. Web sahifada "Code" bo'limini quyidagicha to'ldiring:
   - Source code: /home/<sizning_username>/mysite
   - Working directory: /home/<sizning_username>/mysite

5. "WSGI configuration file" havolasi ustiga bosing (masalan: /var/www/<username>_pythonanywhere_com_wsgi.py).
   Fayl ichidagi barcha narsani o'chirib, o'rniga quyidagini yozing va "Save" tugmasini bosing:

import sys
import os

path = '/home/<sizning_username>/mysite'
if path not in sys.path:
    sys.path.insert(0, path)

from wsgi import application

   (Eslatma: <sizning_username> o'rniga o'zingizning PythonAnywhere username'ingizni yozing!)

6-QADAM: STATIK FAYLLARNI ULASH (CSS, JS, RASMLAR)
---------------------------------------------------------------
"Web" sahifasida "Static files" bo'limiga tushing va quyidagini qo'shing:
   - URL: /static/
   - Directory: /home/<sizning_username>/mysite/static

7-QADAM: SAYTNI ISHGA TUSHIRISH
---------------------------------------------------------------
1. "Web" sahifasi yuqorisidagi yashil "Reload <username>.pythonanywhere.com" tugmasini bosing.
2. Saytingiz tayyor: https://<username>.pythonanywhere.com

8-QADAM: MOBIL ILOVANI SERVERGA ULASH
---------------------------------------------------------------
Android telefoningizdagi BeeAnaliz ilovasiga kiring:
- O'ng yuqoridagi tishli g'ildirak (Sozlamalar) belgisini bosing.
- Server manzili joyiga:
  https://<username>.pythonanywhere.com
  deb yozing va "Saqlash" tugmasini bosing.
Endi telefon ilovasi butun dunyo bo'ylab istalgan internetdan serveringizga ulanadi!
